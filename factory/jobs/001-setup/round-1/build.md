# Round 1
## Changes
- pyproject.toml: generated by `uv init --package` (Q1: `uv_build` backend, src layout). Runtime deps fastapi, uvicorn, jinja2. Dev group pytest, httpx. `[project.scripts] fctl = "claude_factories.cli:main"`.
- uv.lock: generated by `uv add`.
- .python-version: `3.12`, written by `uv init`. Pins uv's interpreter to the §4.2 version.
- .gitignore: `.venv/`, `__pycache__/`, `.pytest_cache/`, `dist/` (AC29).
- src/claude_factories/__init__.py: empty, so `import claude_factories.cli` doesn't pull in the app (AC3).
- src/claude_factories/cli.py: stdlib only. `main(argv=None)` uses argparse with a required `serve` subcommand that has only `--port` (default 4545). `serve` imports uvicorn, db, and app inside the function, prints the Q6 banner (flushed), then calls `uvicorn.run(app, host="127.0.0.1", port=…)`. `api(method, path, body=None)` uses urllib, always sends `X-Requested-By: fctl`, and sends JSON with `Content-Type: application/json` when there's a body. It decodes by content type. Errors follow Q8: `fctl: <status> <detail>` on stderr, exit 1. Any `OSError` (refused, reset) prints the AC28 message, also exit 1.
- src/claude_factories/db.py: stdlib only. `data_dir()` (`FCTL_HOME`, else `~/.claude-factories`), `connect()` (sets `PRAGMA foreign_keys = ON` on every connection, Q3), and `init()` (mkdir with parents and exist_ok, Q10; WAL; `executescript(schema.sql)`).
- src/claude_factories/schema.sql: §5.1 copied verbatim from docs with `IF NOT EXISTS` added to the 10 `CREATE TABLE` lines and to `CREATE UNIQUE INDEX` (Q2). `diff` against docs shows only those 11 lines changed.
- src/claude_factories/app.py: the FastAPI `app`. Its lifespan calls `db.init()`. It mounts `/static` and sets up Jinja2Templates. `GET /` renders `index.html`. The `local_safety` HTTP middleware wraps everything, `/static` included. It checks the Host hostname first, comparing only the part before `:`, lowercased, against `{127.0.0.1, localhost}`, so a missing Host is rejected (Q4). It then requires `X-Requested-By: fctl` on every method except GET, HEAD, and OPTIONS (Q8). Both checks return 403 with JSON `detail`.
- src/claude_factories/templates/base.html: color-scheme meta, the light and dark highlight.js theme `<link>`s with `media` queries, the htmx and highlight.js `<script>`s, and `<body hx-headers='{"X-Requested-By": "fctl"}'>`. It doesn't call `hljs.highlightAll()` (Q5).
- src/claude_factories/templates/index.html: extends base. Contains `<h1>Claude Factories</h1>` and "No projects yet." (Q7).
- src/claude_factories/static/*: vendored and unmodified (Q5):
  - htmx 2.0.11 (latest 2.0.x on npm): https://unpkg.com/htmx.org@2.0.11/dist/htmx.min.js. sha256 d6fdc75f…f717. Upstream's minified dist file has no license header, so there was none to keep (htmx is 0BSD).
  - highlight.js 11.12.0 (latest 11.x on npm, common bundle): https://unpkg.com/@highlightjs/cdn-assets@11.12.0/highlight.min.js. sha256 8ab71eb0…7f53. BSD-3 header kept.
  - https://unpkg.com/@highlightjs/cdn-assets@11.12.0/styles/github.min.css. sha256 3a9a5def…f066.
  - https://unpkg.com/@highlightjs/cdn-assets@11.12.0/styles/github-dark.min.css. sha256 9f208d02…9019.
- tests/conftest.py: an autouse `isolated` fixture. It sets `FCTL_HOME` to `tmp_path/fctl-home` (not created), unsets `FCTL_URL` so tests never reach a real server, and puts `tmp_path/bin/claude` (`#!/bin/sh` + `exit 0`, Q9) first on PATH. It also has a `client` fixture: `TestClient(app, base_url="http://127.0.0.1:4545")`.
- tests/test_cli.py, tests/test_db.py, tests/test_app.py: one test per AC, plus one Q8 test for the error-detail fallbacks.

Q1 wheel check, run by hand: `uv build --wheel --out-dir <scratchpad>`. It produced `claude_factories-0.1.0-py3-none-any.whl` containing `schema.sql`, `templates/base.html`, `templates/index.html`, and all 4 `static/` files, plus `entry_points.txt` for `fctl`. No `dist/` was left in the worktree.

Manual smoke test: `FCTL_HOME=<scratch> fctl serve --port 45991` printed the banner followed by uvicorn's own lines. `GET /` returned 200. `Host: evil.example` returned 403. `POST /x` without the header returned 403. `api('POST','/nope')` printed `fctl: 404 Not Found` and exited 1. `factory.db` was created.

## Open questions
- Q1 → `uv_build` from `uv init --package` (uv 0.8.20). The wheel includes all package data (checked above).
- Q2 → added `IF NOT EXISTS` only. Nothing else changed.
- Q3 → `db.connect()` sets `foreign_keys=ON` on every connection.
- Q4 → Host is checked on every request. Only the hostname is compared, case-insensitively, ignoring the port. A missing Host is rejected. The response is 403 JSON.
- Q5 → htmx 2.0.11 and highlight.js 11.12.0, with the URLs above. The htmx min file has no upstream license header.
- Q6 → banner as specified, using `db.data_dir()`.
- Q7 → placeholder `index.html` as specified.
- Q8 → as specified. If an error body is JSON without `detail`, or isn't JSON at all, the raw body text is used. An empty body falls back to the HTTP reason phrase, e.g. `fctl: 404 Not Found`, so there's no trailing blank.
- Q9 → `#!/bin/sh` + `exit 0`. `HOME` is overridden only in AC9's test.
- Q10 → `mkdir(parents=True, exist_ok=True)`, default umask.
- New: Starlette 1.8 warns `Using httpx with starlette.testclient is deprecated; install httpx2 instead.` I kept `httpx`, since FACTORY.md and the spec name it as the dev dependency. Switching to `httpx2` is a one-line dev-dependency change if you want it.
- New: there's no range check on `--port`. argparse checks that it's an int, and uvicorn reports bind errors itself.
